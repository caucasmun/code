## 📖 О проекте

Школьники часто воспринимают программирование как абстрактную теорию:
синтаксис, правила, задачи без визуальной обратной связи. Это снижает
мотивацию. **«Код в игре»** решает проблему через геймификацию: мини-игры
дают мгновенную обратную связь, а разбор кода превращает абстракции
в понятные примеры.

> 🎯 **Цель:** создать сайт, который помогает школьникам осваивать основы
> программирования через мини-игры и пошаговый разбор кода.

**Целевая аудитория:** школьники 7–11 классов, начинающие изучать
программирование; учителя информатики как вспомогательный инструмент.

## ✨ Возможности

| | Возможность | Описание |
|---|---|---|
| 🎮 | **Мини-игры** | Интерактивные задания на переменные, условия, циклы, функции. Мгновенная обратная связь и объяснение ошибок. |
| 🔍 | **Разбор кода** | Пошаговый разбор фрагментов с подсветкой синтаксиса и комментариями к каждой строке. |
| 📊 | **Прогресс** | Отслеживание пройденных игр и разборов, сохраняется между сессиями (Redux + localStorage). |
| 🌗 | **Светлая и тёмная тема** | Переключение тумблером, сохранение выбора, учёт системной темы (`prefers-color-scheme`). |
| 📱 | **Адаптивность** | Мобильные (320px+), планшеты (768px+), десктопы (1024px+). |
| ⚡ | **Клиентская навигация** | Без перезагрузки страницы (React Router). |

## 🗺️ Структура страниц

```text
/                  — Главная: hero, о проекте, CTA
/games             — Каталог мини-игр
/games/:id         — Конкретная игра
/code              — Разбор кода (список примеров)
/code/:id          — Пошаговый разбор фрагмента
/profile           — Прогресс и настройки
```
